# Observatory

**Локальная панель наблюдения за сетью OpenWrt — устройства, трафик, здоровье роутера и проверяемые ограничения точности.**

[English](README.en.md) · [Безопасность](SECURITY.md) · [Лицензия](LICENSE)

![Version](https://img.shields.io/badge/version-0.4.0-d5a34c) ![Languages](https://img.shields.io/badge/languages-RU%20%7C%20EN-7d9b65) ![Storage](https://img.shields.io/badge/data-local%20only-334b35)

## Возможности

Обзор устройств DHCP/ARP/NDP, счётчики трафика, нагрузка/память/температура, графики, события, отчёты CSV/JSON. Дополнительная оценка доменов и маршрутов доступна только при явно включённых интеграциях. Интерфейс на русском и английском; язык наследуется от LuCI или выбирается в панели. Поддерживается оформление [ЗОНА](https://github.com/vivolabboo-cyber/luci-theme-zona).

## Безопасные исходные настройки

- Установка **не запускает сборщик и не включает автозапуск**.
- DNS-атрибуция, подробности соединений и доступ к Tachyon выключены по умолчанию.
- База по умолчанию в `/tmp`: данные теряются после перезагрузки и не изнашивают flash. Срок истории — 7 дней, мягкий лимит БД — 32 МиБ; лимит не является строгой квотой файловой системы.
- Каталоги данных 0700, файлы 0600; RPC читает только снимки и отчёты через аутентификацию/ACL LuCI.
- Нет отправки данных в облако и новых слушающих HTTP-портов. Нет автоматического перезапуска rpcd, изменения DNS или VPN.
- Сборщик требует root для собственных nft-счётчиков. Он создаёт отдельную таблицу `inet observatory` со счётчиками, без drop/redirect/mark. Это мониторинг, но не полностью бездействующий процесс.

## Установка

Через SSH от root скачайте установщик:

```sh
wget -O /tmp/luci-app-observatory-install.sh https://github.com/vivolabboo-cyber/luci-app-observatory/releases/download/v0.4.0/bootstrap.sh
```

Просмотрите скрипт, затем запустите:

```sh
sh /tmp/luci-app-observatory-install.sh --install-deps
```

Установщик скачивает фиксированную версию по HTTPS и проверяет SHA-256 архива. Контрольная сумма не заменяет подпись: источником доверия остаются GitHub и сам установщик.

`--install-deps` устанавливает зависимости через apk/opkg из настроенных репозиториев прошивки. Сбор и автозапуск остаются выключенными до проверки конфигурации LAN/WAN.

Ручная установка:

Требуются LuCI, rpcd, nftables, ip-full и Python 3 с sqlite3/urllib. Для OpenWrt с APK: `apk add python3-light python3-sqlite3 python3-urllib ip-full nftables rpcd`; на старых версиях — соответствующие пакеты через opkg. Проверяйте имена пакетов своего релиза. Скрипт установки зависимости сам не скачивает.

Скачайте исходники/релиз, проверьте SHA256SUMS, скопируйте на роутер и выполните `sh install.sh`. Заменяемые файлы сохраняются в закрытом `/root/observatory-backup-*`. Настройте `/etc/observatory/config.json` по `config/config.example.json`: LAN/WAN-интерфейсы должны соответствовать вашей схеме. Доступную стандартную SSH-сессию сохраняйте открытой.

После проверки настроек вручную выполните `/etc/init.d/rpcd restart` (может потребоваться повторный вход), затем `/etc/init.d/observatory start`. Это явное включение сбора сведений о локальных устройствах. Для желаемого автозапуска: `/etc/init.d/observatory enable`. Панель: **Статус → Observatory**.

## Интеграции — только по выбору

`collect_connection_details: true` включает чтение conntrack и подробностей соединений. `tachyon_enabled: true` дополнительно разрешает локальный Clash-compatible API, параметры которого читаются на самом роутере из `/etc/tachyon-core/config.json`. Разрешены только loopback/неопределённый локальный bind; LAN/внешние адреса не опрашиваются, API наружу не открывается. Секрет API не возвращается интерфейсу.

`dns_enabled: true` разрешает чтение заранее настроенного приватного DNS-журнала. Проект **не включает DNS-логирование сам**: это сознательный сбор чувствительных метаданных. Не сохраняйте реальную конфигурацию, домены или выгрузки в Git. Для постоянной БД вручную выберите приватное хранилище вне `/www`.

## Что цифры не означают

Счётчики включают локальный/служебный трафик. DNS-запрос — не посещение страницы. Доменные объёмы — оценка; HTTPS-содержимое не читается. Короткие соединения, CDN, ECH, offload и прокси могут ограничивать атрибуцию. Имена и MAC не идентифицируют человека. Производительность на большой сети не гарантируется.

Отчёты содержат локальные идентификаторы и домены: проверьте перед передачей. Обезличивание экспорта не включено автоматически.

## Разработка и удаление

`python3 tools/check.py`, `python3 -m unittest discover -s tests`, `python3 tools/package.py`. Makefile — для OpenWrt SDK. В `docs/demo` только искусственные данные; демонстрация не соединяется с роутером. Публичная версия проверяется локально и не заменяет установленную домашнюю службу при публикации.

`sh uninstall.sh` останавливает службу и удаляет программные файлы, но сохраняет конфигурацию, историю и резервные копии. Возврат файлов: распакуйте нужную копию из `/root/observatory-backup-*`, затем отдельно решите, запускать ли службу. Лицензия Apache-2.0. Независимый аудит не проводился.

## Диагностика устройства (0.4.0)

Во вкладке «Диагностика» выберите устройство, повторите проблемное действие и подождите 15–30 секунд. Фильтры показывают DNS-ответы, соединения без ответных данных, маршрут VPN/Zapret2 и объём передачи. В списке устройств — короткое имя и один IP; накопленные IPv6-адреса доступны отдельно после выбора. Обновление каждые 5 секунд.

Наблюдения хранятся только в RAM: до 1500 записей на всю сеть за последние два часа. Перезапуск сборщика очищает эту историю. Подробности соединений требуют явного `collect_connection_details: true`; метаданные маршрутов — `tachyon_enabled: true` и API Tachyon на loopback; DNS — `dns_enabled: true` и уже настроенный закрытый журнал dnsmasq с идентификаторами запросов. Обычные DNS-журналы без идентификаторов нельзя надёжно сопоставить: отсутствие записи не считается таймаутом.

«Нет ответных данных» — подозрение, а не доказанная блокировка. UDP бывает односторонним, NXDOMAIN может быть штатным ответом, а отсутствие AAAA — нормальным для IPv4-узла. Ответные байты не подтверждают успешный HTTP-запрос или воспроизведение. Полные URL, HTTP-коды и содержимое HTTPS не собираются.

При обновлении остановите только Обсерваторию, выполните установщик, затем перезапустите rpcd для регистрации нового метода и запустите сборщик. Перезапуск rpcd может потребовать повторного входа в LuCI; VPN перезапускать не требуется. Сохраняйте резервную копию программы и базы перед обновлением.
